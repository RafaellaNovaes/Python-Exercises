Python-Exercises

Exercícios de Python passados pelo professor na faculdade, feitos e documentados no Google Colab.

Sobre

Este repositório reúne os exercícios de Python, resolvidos no Google Colab. A ideia é praticar os conceitos vistos em aula e manter um histórico organizado de cada lista/exercício.

Como abrir

O arquivo é um notebook (.ipynb). Você pode:

Abrir direto no Google Colab (upload do arquivo ou "Abrir do GitHub"), ou
Rodar localmente com Jupyter Notebook / Jupyter Lab:
bash
git clone https://github.com/RafaellaNovaes/Python-Exercises.git
cd Python-Exercises
jupyter notebook
Tecnologias
Python 3
Google Colab
